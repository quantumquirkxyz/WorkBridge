# prod-prd-writing

When to use: Write Product Requirement Documents (PRDs) — problem statement, goals, user stories, acceptance criteria, success metrics, timeline — with stakeholder alignment.

## Workflow

1. Problem statement
2. Goals
3. User stories
4. Success metrics
5. Constraints and risks
6. Timeline and milestone

## Deliverables

- pull-request artifact

## Guardrails

- risk: low; trust tier: 1; approval required: no
- side effects: none
- isolation: none; model tier: reasoning

Stop when: PRD saved; stakeholder alignment noted; metrics defined.
