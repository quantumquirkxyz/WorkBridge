# serverless

When to use: Serverless architecture (Lambda, Functions, FaaS, event-driven, cold starts, scaling, cost).

## Workflow

1. Inventory workloads and event sources
2. Define function boundaries and triggers
3. Design cold start and scaling strategy
4. Plan state, storage, and integration
5. Configure observability and logging
6. Estimate cost and define budgets

## Deliverables

- backend artifact

## Guardrails

- risk: medium; trust tier: 3; approval required: yes
- side effects: none
- isolation: none; model tier: reasoning

Stop when: Serverless architecture, event sources, scaling behavior, and cost model are explicit.
