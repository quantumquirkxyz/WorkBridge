# grill-with-docs

When to use: A relentless interview to sharpen a plan or design, while creating docs (ADRs and glossary) as we go.

## Workflow

1. Identify the plan or design to grill and the documentation artifacts likely to emerge
2. Question assumptions, terms, boundaries, and decision criteria
3. Convert stable answers into ADR, glossary, or context-pack notes
4. Keep unresolved disagreements visible instead of documenting them as settled
5. Summarize the refined plan and docs to create or update

## Deliverables

- adr artifact

## Guardrails

- risk: low; trust tier: 2; approval required: no
- side effects: write-docs
- isolation: none; model tier: router

Stop when: A relentless interview to sharpen a plan or design, while creating docs (ADRs and glossary) as we go complete; artifact saved; completion criteria checked.
