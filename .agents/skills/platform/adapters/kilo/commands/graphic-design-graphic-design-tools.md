# graphic-design-tools

When to use: Connect graphic design tools — Figma, Adobe Creative Cloud, Canva, and local production tools — to agent workflows with explicit authentication, scopes, and safety boundaries.

## Workflow

1. Inventory the tool landscape
2. Evaluate integration options per tool
3. Define authentication and access policy
4. Map use cases and data flow
5. Design safety boundaries
6. Specify implementation path

## Deliverables

- plan artifact

## Guardrails

- risk: medium; trust tier: 3; approval required: yes
- side effects: none
- isolation: none; model tier: reasoning

Stop when: Graphic design tools integration plan complete; tool selection, authentication, use cases, and safety boundaries explicit.
