# brainstorming

When to use: Facilitate structured, inclusive brainstorming that turns an ambiguous problem into prioritized, testable ideas.

## Workflow

1. Frame
2. Diverge
3. Converge
4. Test

## Deliverables

- product-discovery artifact

## Guardrails

- risk: low; trust tier: 1; approval required: no
- side effects: none
- isolation: none; model tier: reasoning

Stop when: The problem is framed, ideas are captured and clustered, priorities are justified, and next experiments have owners and acceptance criteria.
