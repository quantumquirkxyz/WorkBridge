# brand-identity

When to use: Design brand identity systems — logo, color, typography, imagery, iconography, voice, and usage rules — with explicit consistency, scalability, and governance.

## Workflow

1. Define brand strategy and positioning
2. Design the logo system
3. Establish the color palette
4. Define typography system
5. Define imagery and iconography style
6. Document usage governance

## Deliverables

- graphic-design artifact

## Guardrails

- risk: low; trust tier: 1; approval required: no
- side effects: none
- isolation: none; model tier: reasoning

Stop when: Brand identity design complete; strategy, visual system, and usage rules explicit; governance named.
