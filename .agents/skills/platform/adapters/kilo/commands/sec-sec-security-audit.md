# sec-security-audit

When to use: Audit software/security posture — code review, dependency scanning, secret detection, access control, audit logging — with explicit findings and remediation priorities.

## Workflow

1. Scope
2. Threat model (optional but recommended)
3. Code review
4. Dependency / secret scan
5. Classify findings
6. Remediation priorities
7. Report

## Deliverables

- security artifact

## Guardrails

- risk: medium; trust tier: 3; approval required: yes
- side effects: none
- isolation: none; model tier: reasoning

Stop when: Audit report complete; findings classified by severity; recommendations made.
