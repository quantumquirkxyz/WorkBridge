# accessibility

When to use: Design inclusive products — WCAG compliance, assistive technology support, keyboard navigation, color contrast — with explicit user access guarantees.

## Workflow

1. **Audit with automated tools** — catch low-hanging fruit
2. **Test with keyboard** — tab through every flow
3. **Test with screen reader** — announce each element
4. **Review color contrast** — check all text/background pairs
5. **Fix by severity** — A first, then AA
6. **Document** — accessibility statement and test results

## Deliverables

- accessibility artifact

## Guardrails

- risk: low; trust tier: 1; approval required: no
- side effects: none
- isolation: none; model tier: reasoning

Stop when: Design inclusive products complete; artifact saved; completion criteria checked.
