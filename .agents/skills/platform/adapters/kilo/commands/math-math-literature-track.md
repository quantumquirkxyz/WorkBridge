# math-literature-track

When to use: Track mathematics literature across arXiv, MathSciNet, zbMATH, journal alerts, and citation graphs to keep a researcher current without drowning in papers.

## Workflow

1. Define the tracking set
2. Pull from primary sources
3. Score relevance
4. Group
5. Deliver the digest

## Deliverables

- math artifact

## Guardrails

- risk: low; trust tier: 1; approval required: no
- side effects: none
- isolation: none; model tier: reasoning

Stop when: digest artifact saved with grouped papers and relevance scores; all sources cited.
