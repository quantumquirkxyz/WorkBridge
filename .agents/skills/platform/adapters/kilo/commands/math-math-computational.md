# math-computational

When to use: Solve numerical and symbolic math problems (root finding, integration, ODEs, symbolic manipulation) with stable algorithms and explicit error analysis.

## Workflow

1. Frame the problem
2. Choose the algorithm
3. Estimate error and stability
4. Implement / compute
5. Verify
6. Deliver

## Deliverables

- math artifact

## Guardrails

- risk: low; trust tier: 1; approval required: no
- side effects: none
- isolation: none; model tier: reasoning

Stop when: Artifact contains algorithm, error bounds, verification, and final answer; solution is reproducible from the code shown.
