# graphic-design-project-management

When to use: Manage graphic design projects — briefs, iterations, reviews, asset handoff, versioning, and delivery — with explicit scope, timelines, and quality gates.

## Workflow

1. Define project scope and deliverables
2. Plan timeline and milestones
3. Design iteration cycles
4. Define review gates and approval workflow
5. Specify asset handoff standards
6. Document quality gates
7. Plan stakeholder communication

## Deliverables

- plan artifact

## Guardrails

- risk: low; trust tier: 2; approval required: no
- side effects: none
- isolation: none; model tier: fast

Stop when: Graphic design project management plan complete; scope, timeline, iterations, reviews, and handoff standards explicit.
