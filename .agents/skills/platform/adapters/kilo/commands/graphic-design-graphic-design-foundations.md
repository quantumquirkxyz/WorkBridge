# graphic-design-foundations

When to use: Design graphic artifacts — posters, social graphics, editorial layouts, packaging, signage — with explicit composition, color, typography, and production constraints.

## Workflow

1. Clarify the brief and constraints
2. Define composition and visual hierarchy
3. Design the color system
4. Select typography
5. Specify production requirements

## Deliverables

- plan artifact

## Guardrails

- risk: low; trust tier: 1; approval required: no
- side effects: none
- isolation: none; model tier: reasoning

Stop when: Graphic design foundations complete; layout, color, and typography decisions explicit; production requirements named.
