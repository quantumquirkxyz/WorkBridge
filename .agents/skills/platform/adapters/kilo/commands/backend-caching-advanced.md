# caching-advanced

When to use: Advanced caching strategies (Redis, Memcached, CDN, cache invalidation, stampede prevention).

## Workflow

1. Analyze access patterns and requirements
2. Select cache stores and layers
3. Design key strategy and data shape
4. Plan invalidation and consistency
5. Implement stampede prevention
6. Configure observability and operations

## Deliverables

- backend artifact

## Guardrails

- risk: medium; trust tier: 3; approval required: yes
- side effects: none
- isolation: none; model tier: reasoning

Stop when: Cache architecture, invalidation strategy, stampede prevention, and consistency model are explicit.
