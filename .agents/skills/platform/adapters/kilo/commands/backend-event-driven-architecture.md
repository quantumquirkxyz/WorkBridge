# event-driven-architecture

When to use: Event-driven architecture (Kafka, NATS, EventBridge, choreography vs orchestration).

## Workflow

1. Inventory events and workflows
2. Choose messaging pattern
3. Design topics, streams, and queues
4. Define event schema and contracts
5. Plan delivery guarantees and idempotency
6. Design observability and operations

## Deliverables

- backend artifact

## Guardrails

- risk: medium; trust tier: 3; approval required: yes
- side effects: none
- isolation: none; model tier: reasoning

Stop when: Event-driven architecture design complete; artifact saved; completion criteria checked.
