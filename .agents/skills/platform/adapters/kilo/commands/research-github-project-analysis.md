# github-project-analysis

When to use: Research comparable projects exclusively on GitHub and analyze their structure, decisions, and reusable patterns for an active project.

## Workflow

1. Define comparison frame
2. Discover and triage GitHub repositories
3. Inspect structure deeply
4. Compare and adapt
5. Report uncertainty

## Deliverables

- research-report artifact

## Guardrails

- risk: medium; trust tier: 3; approval required: no
- side effects: none
- isolation: none; model tier: reasoning

Stop when: Comparable GitHub repositories are selected with evidence, their structures are compared, adaptations are bounded, and unresolved risks are recorded.
