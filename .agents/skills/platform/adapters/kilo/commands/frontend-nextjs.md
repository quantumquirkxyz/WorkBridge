# nextjs

When to use: Shape Next.js projects around routes, server/client seams, and data flow that stay deep rather than tangled.

## Workflow

1. Identify the primary user path and route shape
2. Decide the server/client split at the seam
3. Note any data-fetching or rendering constraints
4. Describe the smallest route structure that still fits the flow

## Deliverables

- frontend artifact

## Guardrails

- risk: low; trust tier: 1; approval required: no
- side effects: none
- isolation: none; model tier: reasoning

Stop when: Shape Next complete; artifact saved; completion criteria checked.
