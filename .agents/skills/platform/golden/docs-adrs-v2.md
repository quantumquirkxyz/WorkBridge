# ADRs

## Phase 1: Gather Context
- Identify the decision
- List constraints
- Note stakeholders

## Phase 2: Document Decision
- State the problem
- List alternatives
- Record the decision
- Document consequences

## Phase 3: Validate
- Review completeness
- Check clarity
- Emit ADRDocument
