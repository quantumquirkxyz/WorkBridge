# To Spec

## Phase 1: Gather Context
- Read the conversation or requirements
- Identify the goal
- Note constraints

## Phase 2: Draft Spec
- Define the problem
- List requirements
- Define acceptance criteria

## Phase 3: Validate
- Check completeness
- Ensure testability
- Emit SpecArtifact
