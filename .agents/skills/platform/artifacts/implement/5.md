## Changes

- Bootstrapped an npm-workspaces TypeScript monorepo (strict tsconfig, Vitest, ESLint).
- `packages/domain`: `JobRequirements` JSON Schema 2020-12 contract, Ajv 2020-12
  validator and error types, and the ESCO-based Panamanian skills taxonomy with
  exact/alias/fuzzy matching.
- `apps/agent-runtime`: vacancy normalization pipeline accepting manual, JSON,
  PDF, and image inputs behind an injectable extraction port.
- Separated mandatory and desirable requirements and mapped them to canonical
  taxonomy skills while preserving original wording.
- Classified fairness alerts as `ambiguous`, `potentially_discriminatory`, or
  `prohibited`; blocked prohibited requirements; routed ambiguous and
  potentially discriminatory requirements to human review; excluded flagged
  requirements from ranking with reviewer resolution.
- Added fixtures (objective, good appearance, unjustified age limit, mixed,
  free-text, real PDF) and 64 Vitest tests.
