## Changes

- Every one of the 23 seed skills now has a verified `escoUri` resolved against
  ESCO **v1.2.1**; each referenced concept had `status=released`.
- `escoLabel` now records the verified English preferred label of the resolved
  concept. Original `labelEs`, `labelEn`, and aliases are unchanged.
- The taxonomy records `escoVersion`, `escoResolvedAt`, and `escoResolution`,
  and `provenance` explains how the URIs were resolved and verified.
- `SkillTaxonomy`/`TaxonomySkill` expose the ESCO provenance fields, including
  an optional `escoUnmappedReason` for concepts that cannot be mapped.
- A contract test guards URI format, URI uniqueness, the recorded version,
  the unmapped-reason escape hatch, and localized label preservation.

## Risk remaining

ESCO concept selection is semantic: several original seed labels were
approximations, so `escoLabel` now reflects the verified ESCO preferred label
rather than the original seed wording. Re-verification requires network access
and the GET request recorded in `escoResolution`; no resolver script is
committed. A later ESCO release may retire or replace concepts.
