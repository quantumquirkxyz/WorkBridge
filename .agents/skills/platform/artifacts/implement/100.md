# Issue 100 implementation

Source: https://github.com/HackathonFISC/equipo-02/issues/100

Employers get `GET /vacancies/:vacancyId/shortlist`: applications already received for a vacancy their organization owns, ranked by the deterministic score (desc, then candidate id, then submission id), each with gap summaries and bias alerts from the merged counterfactual auditor. Other organizations get 403, anonymous 401, unknown vacancy 404. No vacancy publishing or employer search (scope per the 12:23 clarification on the issue). Candidate identifiers are not returned.

Seam: ApplicationService read method, trusted ShortlistSource, BFF proxy. No UI: /empresa has no per-vacancy view to host the ranking cheaply.

Validation: focused service, server and BFF tests pass; ESLint and git diff --check pass; tsc shows only pre-existing errors. Unrelated chat-worker test failure belongs to the chat work (#115).
