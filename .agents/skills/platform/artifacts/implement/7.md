## Changes

- Added the **`CandidatePreferences`** contract (JSON Schema 2020-12,
  `packages/domain`): target roles, modality, maximum location, max travel
  time, monthly transport budget, minimum salary, availability, contract
  types, transport modes, and course/internship willingness.
- Guarded against inference: the contract requires
  `origin = candidate_explicit`, and `buildPreferences` maps the form payload
  straight onto the contract with no model call.
- Added **`@puente/catalog`**, the cached-vacancy seam: `CachedVacancy` and
  `ExplorationResult` contracts, validated by the shared Ajv instance from
  `@puente/domain`.
- `toCachedVacancy` / `loadCatalogFromScraped` preserve **`jobId`, `jobUrl`,
  `queriedAt` (query date), and `scrapingInfo`** verbatim beside the normalized
  view.
- `computeFreshness` (default **72 h**) measures age from `postedAt` and returns
  a dashboard-ready Spanish label; `exploreVacancies` excludes stale vacancies
  **before** any compatibility check.
- Deterministic filters: stale → modality → location → internship/contract →
  schedule → salary, with provenance and freshness on every match and a Spanish
  reason on every exclusion.
- Added the deterministic **`ExplorationAgent`** in `apps/agent-runtime`.
- Added the **Spanish candidate dashboard** (`apps/web`) with the explicit
  preferences form and match/exclusion tables, plus `/api/preferences` and
  `/api/explore` routes over a pure handler and an in-memory store.
- Fixed two pre-existing lint blockers: eslint now ignores `.next` output, and
  the tesseract dynamic import uses a typed module shape instead of `any`.

## Remaining risk

- Preferences are persisted in an in-process store; a durable
  PostgreSQL/Prisma store should replace it behind the same `PreferencesStore`.
- The catalogue is served from the bundled fixture until the Apify LinkedIn Jobs
  refresh is wired, so freshness reflects fixture `postedAt` values.
- Skill affinity in exploration is a pre-match heuristic over target-role
  taxonomy ids; the solver still owns hard skill constraints.
- **Playwright was not run** (no `@playwright/test` dependency or browser in the
  workspace). Per the agreed approach, the same seam is covered by deterministic
  Vitest handler tests plus a live HTTP smoke test.
