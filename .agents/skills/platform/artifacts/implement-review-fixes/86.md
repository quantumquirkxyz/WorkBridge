# Implement Review Fixes — PR #86

Status: implemented

Source of truth: [Review Fix Plan](https://github.com/HackathonFISC/equipo-02/pull/86#issuecomment-6232349238) (fixed point `origin/main`).

## Completed

- **Preserve initial quick replies.** `ChatScreen` now renders the greeting
  slot definition for an entirely empty session, so the first welcome message
  keeps its quick-reply chip and a new candidate can start the fallback journey
  without typing. Seeded chips now carry the definition's own slot id.
- **Scope saved preferences by candidate.** Explored preferences are written
  and read under `puente:preferences:<candidateId>` via a shared
  `lib/preferences-storage` helper. The chat, dashboard, and save-search flows
  all use the candidate-scoped key; the global `puente:preferences` key is gone
  and the UC-07 e2e seeds the scoped key.
- **Compare session expiry numerically.** `actorFromBetterAuthSession` compares
  `Date.parse(expiresAt)` with `Date.parse(nowIso)` instead of comparing ISO
  strings lexicographically.
