# Grid Systems

## Modular Grids

### Baseline Grid
- Horizontal lines at consistent vertical intervals (often based on body text leading).
- Ensures all text aligns across columns and margins.
- Use for: academic journals, structured reports, technical documentation.
- Typical baseline: 12–18 pt depending on body size.

### Manuscript Grid
- Single-column format with generous margins.
- Use for: poetry, novels, letters, personal narratives.
- Margins often asymmetric to accommodate binding.

### Column Grid
- Multi-column layout with gutters between columns.
- Use for: magazines, newspapers, newsletters, textbooks.
- Typical columns: 2–6 depending on page width and content density.

### Hierarchical Grid
- Asymmetrical zones for images, captions, pull quotes, and running heads.
- Use for: feature magazines, catalogues, branded reports.
- Combines column structure with modular zones.

## Grid Selection by Content Type

| Content Type       | Recommended Grid         | Notes                                  |
|--------------------|--------------------------|----------------------------------------|
| Novel / memoir     | Manuscript               | Focus on readability, minimal columns  |
| Academic journal   | Baseline + Column        | Strict alignment for dense text        |
| Magazine           | Hierarchical + Column    | Varied image sizes, pull quotes        |
| Annual report      | Hierarchical             | Data visualizations, executive summary |
| Newsletter         | Column (2–3)             | Scannable, compact                     |
| Textbook           | Baseline + Column        | Sidebars, callouts, exercises          |

## Margins, Gutters, and Page Proportions

### Margins
- Top: running header clearance, visual breathing room.
- Bottom: page number clearance, visual weight.
- Outside: larger for binding clearance.
- Inside: smaller, consistent with outside margin ratio (often 1:1.5 or golden ratio).
- Gutter: add 3–6 mm for perfect binding; less for saddle-stitch.

### Gutters
- Minimum gutter: 1/6 of column width.
- For multi-column text: maintain gutter at least 1 em of body text.
- Modular grids: gutters define module spacing; keep consistent.

### Page Proportions
- Golden ratio (1:1.618) for single-page emphasis.
- Double-page spreads: use a 2:1 ratio for unified spread balance.
- Common trim sizes: A4 (210×297 mm), A5 (148×210 mm), US Letter (8.5×11 in).
- Custom proportions: establish before grid calculation.

## Digital vs Print Grid Considerations

### Print
- Fixed page size; grids are absolute in mm or points.
- Bleed requires extending grid beyond trim edge.
- Registration marks and crop marks outside bleed area.
- Color separation dictates grid precision.

### Digital
- Fluid widths; grids often percentage or fr-based.
- Breakpoints redefine grid at viewport thresholds.
- Touch targets and line lengths differ from print.
- Pagination may be replaced by scroll; retain grid for section coherence.

## Breaking the Grid Intentionally

- Use sparingly and with clear purpose: emphasis, drama, transition.
- Maintain alignment for at least one major element to anchor the spread.
- Document rule breaks in production notes so layout is reproducible.
- Never break grid for convenience; break for narrative or visual hierarchy.
