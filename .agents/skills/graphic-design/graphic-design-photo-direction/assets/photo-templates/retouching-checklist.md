# Retouching Checklist

## Pre-Retouching Setup

- [ ] Source file opened at full resolution
- [ ] File renamed with version number (e.g., `project_retouch_v001.psd`)
- [ ] White balance and exposure corrected via Camera Raw or adjustment layers
- [ ] Lens correction and perspective correction applied
- [ ] Cropped to final aspect ratio

## Base Correction Layer Group

- [ ] Levels or Curves adjusted for tonal range
- [ ] Exposure and contrast balanced
- [ ] Color temperature corrected
- [ ] Saturation and vibrance adjusted globally
- [ ] HSL adjustments applied for brand color alignment

## Non-Destructive Structure

- [ ] Adjustment layers used instead of direct pixel edits
- [ ] Layer masks applied for localized corrections
- [ ] Smart Objects used for filter applications
- [ ] Layer groups created by category (base, color, local, output)

## Frequency Separation

- [ ] Low-frequency layer created (blur radius appropriate for image scale)
- [ ] High-frequency layer created via Apply Image or subtraction
- [ ] Low-frequency layer edited for skin tone evenness
- [ ] High-frequency layer edited for texture and blemish removal
- [ ] Skin tone checked on vectorscope or color sampler

## Dodge and Burn

- [ ] 50% gray overlay layer created in Overlay or Soft Light mode
- [ ] Dodge (white brush) applied to highlight areas
- [ ] Burn (black brush) applied to shadow areas
- [ ] Sculpting is subtle and gradual
- [ ] No visible halos or unnatural transitions

## Local Corrections

- [ ] Spot healing or cloning completed on high-frequency layer
- [ ] Distractions removed from background or corners
- [ ] Product flaws corrected where appropriate
- [ ] Eye brightening applied for portraits
- [ ] Teeth whitening or eye color enhancement if required

## Background and Compositing

- [ ] Background isolated using appropriate selection method
- [ ] Edges refined and decontaminated
- [ ] New background composited with matching perspective and lighting
- [ ] Contact shadow or reflection added if needed
- [ ] Color matching between subject and background verified

## Color Grading

- [ ] Color grading style applied (cinematic, natural, high-key, low-key)
- [ ] Brand colors matched and verified
- [ ] Skin tones preserved and checked on calibrated monitor
- [ ] Saturation and luminance balanced across color channels
- [ ] Grading is consistent with campaign or brand preset

## Sharpening and Output Preparation

- [ ] Capture sharpening applied early in workflow
- [ ] Creative sharpening applied selectively to focal points
- [ ] Image resized to target output resolution
- [ ] Output sharpening applied at final size
- [ ] No over-sharpening halos visible at 100%
- [ ] File saved in correct format (TIFF/PNG for print, JPEG/WebP for web)
- [ ] Correct color mode (CMYK for print, RGB for web/screen)
- [ ] Metadata and copyright embedded if required
- [ ] Flattened copy saved for delivery
- [ ] Layered master file archived

## Quality Review

- [ ] Image reviewed at 100% zoom for artifacts
- [ ] Image reviewed at fit-to-screen for overall composition
- [ ] Side-by-side comparison with reference images completed
- [ ] Skin tones checked on multiple monitors
- [ ] Brand color accuracy verified with color sampler
- [ ] Output file size is within acceptable bounds
