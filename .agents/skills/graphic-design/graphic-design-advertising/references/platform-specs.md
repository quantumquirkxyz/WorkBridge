# Platform Specs

## Meta (Facebook / Instagram)

- Supported image formats: JPG, PNG
- Max file size: 8.5 MB (feed), 8 MB (some placements)
- Recommended text-to-image ratio: keep overlay text under 20% of image area for best delivery
- Feed aspect ratios: 1:1, 4:5, 9:16
- Story aspect ratio: 9:16
- CTA button: provided by Meta UI, not embedded in creative for most placements
- Video ads: MP4, MOV, max 240 min, 4 GB

## Google Ads

- Responsive display ads: multiple asset sizes recommended (landscape 1.91:1, square 1:1, logo 1:1)
- Image file size: 150 KB recommended limit for faster loading
- Supported formats: JPG, PNG, GIF (non-animated for most placements)
- Leaderboard: 728x90
- Medium rectangle: 300x250
- Mobile leaderboard: 320x50
- Max file size: 150 KB per image asset

## LinkedIn

- Supported formats: JPG, PNG, GIF (non-animated)
- Max file size: 8 MB
- Feed image: 1200x627 (1.91:1) recommended, min 1200x627
- Square: 1080x1080 supported
- Story: 1080x1920 (9:16)
- Video: MP4, MOV, WMV, AVI, FLV, max 5 GB, 10 min

## TikTok

- Supported formats: JPG, PNG, WebP
- Max file size: 20 MB for images
- Video ads: MP4, MOV, max 287.6 MB
- Feed aspect ratio: 9:16
- TopView / Branded Hashtag Challenge: vertical only
- Text overlay: supported but keep minimal; TikTok algorithm favors native content

## Email Client Compatibility

- Max banner width: 600 px (industry standard)
- Supported formats: PNG, JPG, GIF
- Animated GIFs: supported in most clients except Outlook desktop (static fallback required)
- Avoid background images in Outlook; use VML fallback or solid color backgrounds.
- File size per image: keep under 200 KB for faster loading.
- Total email weight: aim under 102 KB to avoid clipping in Gmail.

## File Format and Size Requirements Summary
