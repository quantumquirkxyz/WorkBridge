# Brand Consistency

## Maintaining Brand Identity Across Ad Variations

- Lock brand colors, typography, and logo usage in a shared style guide before generating variations.
- Create a master template and derive channel-specific variants from it rather than redesigning per placement.
- Tag every asset with campaign name, version, and channel so reviewers can trace lineage.

## Template Systems for Campaign Consistency

- Use a single template architecture: master PSD/AI/HTML file with locked symbol layers for logo, headline block, body block, CTA block, and legal block.
- For programmatic or HTML ads, define CSS custom properties for brand colors, font stacks, and spacing scales.
- Maintain a variation matrix: one base template per format family (square, story, landscape) with placeholder rules for channel overrides.

## Color and Typography Application Rules

- Apply primary brand color to CTA and focal elements only; use neutrals for body and supporting copy.
- Use secondary and accent colors for highlights and data visualization, not for large blocks.
- Typography: one display font for headlines, one body font for copy. Do not introduce new fonts mid-campaign.
- Maintain minimum text size by format: desktop display 14 px, mobile story 20 px, print 8 pt.

## Logo Placement and Clear Space

- Place logo in a corner or top center; never obscure the hero image or headline.
- Maintain clear space equal to the height of the logo mark on all sides.
- Use the monochrome or reversed logo version when background contrast is insufficient.
- Do not stretch, rotate, or add effects to the logo in ad executions.

## Voice and Tone in Visual Context

- Match visual style to brand voice: luxury brands use refined imagery and restrained typography; disruptive brands use bold color and kinetic type.
- Consistent illustration or photography style across all executions.
- CTA language should mirror landing page and email messaging to reduce cognitive dissonance.
