# Behavioral Fixture for Graphic Design Project Management

## Expected Output Shape

- Includes project scope and deliverables with acceptance criteria.
- Defines timeline with milestones and critical path.
- Defines iteration schedule with feedback rules.
- Defines review gates with owners, approvers, and criteria.
- Defines asset handoff standards and versioning.
- Defines quality gate checklist with owners.
- Defines stakeholder communication plan.
- Does not claim external project management tools were updated.

## Prohibited Output

- Placeholder-only completion claims.
- Unstated scope or acceptance criteria.
- Generic project management advice not tied to graphic design.
- Claims that external tools were updated without evidence.
