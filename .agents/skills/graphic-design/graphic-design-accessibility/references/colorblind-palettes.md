# Colorblind-Safe Palettes

## Types of Color Blindness

- **Protanopia** — red-blind (1% of males)
- **Deuteranopia** — green-blind (1% of males)
- **Tritanopia** — blue-blind (0.01% of population)
- **Achromatopsia** — monochromacy (0.003% of population)

## Colorblind-Safe Palette Principles

- Avoid red/green combinations as primary differentiators
- Use luminance contrast in addition to hue contrast
- Add patterns, textures, or symbols as redundant encoding
- Test designs in grayscale before adding color
- Use colorblind simulation tools during design process

## Pattern and Texture Fills

- Use hatching, stippling, or cross-hatching in charts
- Add border styles to distinguish regions in maps
- Use different shapes or markers in scatter plots
- Combine color with shape for redundant encoding

## Tools and Simulation Methods

- **Coblis** — online colorblind simulator
- **Colorblind Web Page Filter** — browser-based simulation
- **Figma plugins** — Stark, Color Blind
- **Adobe Color** — accessibility tools and palettes
- **Chromatic Vision Simulator** — mobile app for testing
