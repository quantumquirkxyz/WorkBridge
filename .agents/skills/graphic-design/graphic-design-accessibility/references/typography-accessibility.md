# Typography Accessibility

## Minimum Font Sizes

- **Body text**: minimum 16px (12pt)
- **Captions and footnotes**: minimum 12px (9pt)
- **Headings**: scale proportionally, minimum 24px for h1
- **User interface text**: minimum 14px (10.5pt)

## Line Height and Line Length

- **Line height**: 1.5 times the font size for body text
- **Line length**: 45–75 characters per line (66 ideal)
- **Paragraph spacing**: 2 times the font size between paragraphs
- **Margins**: adequate white space around text blocks

## Font Selection

- **Sans-serif** for UI, menus, and short-form text (Arial, Helvetica, Inter)
- **Serif** for long-form body text when print or high resolution (Georgia, Times)
- **Monospace** for code only, not body text
- Avoid decorative fonts for important content

## Dyslexia-Friendly Fonts

- **OpenDyslexic** — designed to reduce letter confusion
- **Atkinson Hyperlegible** — designed by Braille Institute for low vision
- **Verdana** — widely available with distinct letter shapes
- **Comic Sans** — controversially effective for some dyslexic readers

## Letter Spacing and Word Spacing

- **Letter spacing (tracking)**: at least 0.12 times the font size
- **Word spacing**: at least 0.16 times the font size
- Avoid tight spacing that causes letter crowding
- Increase spacing for all-caps text

## Avoiding All-Caps

- Do not use all-caps for body text or long passages
- All-caps reduces word recognition by up to 15%
- If all-caps is used for emphasis, increase letter spacing
- Limit all-caps to short labels (2–3 words maximum)

## Font Weight

- Minimum regular weight (400) for body text
- Use bold (700) for emphasis, not for entire paragraphs
- Avoid weights below 300 for small text

## Text Alignment

- Left-align body text for readability
- Avoid justified text which creates uneven spacing (rivers)
- Centered text acceptable for short headings only
