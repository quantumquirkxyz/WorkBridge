Accessible Design Principles

  • Use sufficient color contrast (4.5:1 for body text)
  • Support colorblind users with safe palettes
  • Provide readable typography at 16px minimum
  • Include alt text for all meaningful images
  • Enable keyboard navigation for all interactions

Color and Contrast

WCAG 2.1 Level AA requires:

  • 4.5:1 contrast for normal text
  • 3:1 contrast for large text
  • 3:1 contrast for UI components and graphics

Inclusive Typography

  • Minimum 16px body text
  • Line height of 1.5 or greater
  • Avoid all-caps for body text
  • Use dyslexia-friendly fonts when possible
  • Maintain 45–75 characters per line
