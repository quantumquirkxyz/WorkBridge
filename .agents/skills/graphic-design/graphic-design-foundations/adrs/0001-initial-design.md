# 0001 Initial Design for Graphic Design Foundations

## Status
Accepted

## Context
The graphic-design-foundations skill is being created to provide a structured workflow for defining visual direction, composition, color, typography, and production requirements for graphic artifacts.

## Decision
Use the standard quirk skill structure with SKILL.md, references/, scripts/, assets/, adrs/, and behavioral-fixtures/. The skill covers posters, social graphics, editorial layouts, packaging, signage, and presentation covers. It does not connect to external tools or produce final production files.

## Consequences

### Positive
- Provides a repeatable workflow for graphic design planning.
- Keeps production constraints explicit and channel-aware.
- Integrates with accessibility and frontend styling skills through references.

### Negative
- Does not automate production; teams still need design tools for execution.
- Requires manual updates to production standards as formats evolve.
