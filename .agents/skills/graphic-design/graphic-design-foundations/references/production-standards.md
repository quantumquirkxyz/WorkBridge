# Production Standards Reference

## Digital Production

### Resolution
- Web: 72 PPI, vector formats preferred.
- Mobile: 2x and 3x assets for high-DPI screens.
- Presentation: 150–300 PPI depending on display size.

### Color Space
- Web: sRGB standard; Display P3 for premium experiences.
- Mobile: sRGB or Display P3 depending on platform.

### File Formats
- **SVG:** vector graphics, icons, logos, illustrations.
- **PNG:** raster with transparency.
- **JPG:** raster photographs, no transparency.
- **WebP:** modern raster with compression benefits.
- **PDF:** print-ready and archival.

### Compression
- Use lossless for graphics with text or sharp edges.
- Use lossy for photographs.
- Target file size limits: web graphics under 200 KB when possible.

## Print Production

### Bleed and Trim
- Standard bleed: 3 mm (0.125 in) on all sides.
- Safe zone: 5 mm (0.2 in) inside trim.

### Color Space
- CMYK for standard print.
- Pantone for brand-critical colors.

### Resolution
- Minimum 300 PPI at final size.
- Vector formats preferred for logos and text.

### File Formats
- **PDF/X-1a or PDF/X-4:** standard print delivery.
- **AI/EPS:** editable vector for print shops.
- **INDD:** InDesign package for complex layouts.

### Paper and Finishing
- Specify stock weight, coating, and finish.
- Note folding, binding, and trim requirements.

## Handoff Standards
- Layer naming: use descriptive, lowercase-with-hyphens names.
- Group related elements.
- Export assets in required formats with documented naming conventions.
- Include a README with font licenses and color values.
