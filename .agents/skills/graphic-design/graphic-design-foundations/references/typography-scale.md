# Typography Scale Reference

## Modular Scale
A modular scale creates harmonious type sizes by multiplying a base size by a consistent ratio.

### Common Ratios
- **Major Third (1.25):** compact, readable for UI and editorial.
- **Perfect Fourth (1.333):** balanced hierarchy.
- **Golden Ratio (1.618):** dramatic hierarchy for posters and display.

## Type Pairing Principles
- **Contrast:** pair a display face with a complementary body face.
- **Neutral body:** use a neutral serif or sans-serif for long-form reading.
- **Expressive display:** use a distinctive face for headlines only.
- **Limit families:** one or two typefaces per project maximum.

## Scale Examples

### Compact Digital Scale (ratio 1.25, base 16px)
- Display: 32px
- H1: 25.6px
- H2: 20.48px
- Body: 16px
- Small: 12.8px
- Caption: 10.24px

### Editorial Scale (ratio 1.333, base 12pt)
- Display: 28pt
- Headline: 21pt
- Subhead: 16pt
- Body: 12pt
- Caption: 9pt

## Accessibility Notes
- Minimum body size: 12pt digital, 9pt print.
- Line height: 1.4–1.6 for body text.
- Line length: 45–75 characters per line for readability.
- Avoid all caps for body text.

## Licensing
- Note commercial licenses for each typeface used.
- Prefer open-source fonts for digital distribution when brand allows.
- Embed fonts or convert to outlines for print production.
