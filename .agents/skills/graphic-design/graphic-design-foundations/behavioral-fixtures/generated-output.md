# Behavioral Fixture for Graphic Design Foundations

## Expected Output Shape

- Includes a brief summary with artifact type, audience, channel, and brand constraints.
- Describes composition and visual hierarchy in implementation-ready terms.
- Provides a color palette with roles, values, formats, and accessibility notes.
- Provides a typography system with scale, weights, and licensing notes.
- Specifies production requirements for the chosen channel.
- Does not claim production files were created.

## Prohibited Output

- Placeholder-only completion claims.
- Unstated production assumptions.
- Generic aesthetic advice not tied to the brief.
- Claims that final files were produced without evidence.
