# To Tickets

## Phase 1: Analyze Scope
- Read the spec or plan
- Identify vertical slices
- Map dependencies

## Phase 2: Create Tickets
For each slice:
- Define the ticket
- Specify acceptance criteria
- Identify blocking edges

## Phase 3: Validate
- Check ticket completeness
- Ensure traceability
- Emit TicketsArtifact
