# TDD

## Phase 1: Red
- Write a failing test
- Run the test
- Confirm it fails for the right reason

## Phase 2: Green
- Write minimal code to pass
- Run the test
- Confirm it passes

## Phase 3: Refactor
- Clean up the code
- Run tests
- Ensure no regressions
