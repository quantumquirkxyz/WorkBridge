# Puente Laboral Panamá glossary

| Term | Definition |
|---|---|
| Apt | Meets mandatory requirements and practical constraints for a vacancy. |
| Apt with gaps | Can progress after addressing identified gaps. |
| Not currently apt | Fails at least one hard constraint at the current time. |
| Evidence | Information supporting a claim, with provenance and verification state. |
| Informal experience | Relevant activity outside standard formal employment records. |
| Roadmap | Ordered, constrained actions that close a candidate's gaps. |
| Adapted application | Vacancy-specific application content based only on verified or declared facts. |
| Credential verification | Checking document integrity, signer identity, trust, and revocation where supported. |
| Ground truth | Known expected label used to measure verification performance. |
| Workflow graph | State machine connecting agents, tools, fallbacks, and human gates. |
| Human gate | Explicit approval required before an external action. |
