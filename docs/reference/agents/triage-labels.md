# Triage Labels

Triage is part of the standard project flow. These labels are the canonical tracker vocabulary:

| Canonical role | Tracker label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the item |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or merge |
| `wontfix` | `wontfix` | Will not be actioned |
